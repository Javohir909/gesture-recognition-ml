# 🖐️ Gesture Recognition ML Project

**Machine Learning-based Hand Gesture Recognition for Robot Arm Control**

## 📖 Overview

This project uses **Computer Vision** and **Machine Learning** to recognize hand gestures from a webcam feed and control a robotic arm. The system captures hand landmarks using **MediaPipe**, extracts features, and classifies gestures using a trained **Random Forest** model.

### Pipeline

```
Webcam → MediaPipe Hand Detection → Feature Extraction → ML Classifier → Gesture Label
                                                                    ↓
                                                            Arduino Serial → Robot Arm
```

## 🚀 Quick Start

### 1. Install Python dependencies

```bash
pip install -r requirements.txt
```

### 2. Collect data (Step 1)

```bash
python 1_collect_data.py
```

- The webcam will open
- For each gesture (fist, one_finger, two_fingers, etc.):
  - Show the gesture to the camera
  - Press **SPACE** to start collecting
  - Hold the gesture steady until all 200 samples are captured
  - Move to the next gesture automatically
- Press **Q** to quit

### 3. Train the model (Step 2)

```bash
python 2_train_model.py
```

- Loads `data/gesture_dataset.csv`
- Trains a Random Forest classifier
- Evaluates accuracy and shows classification report
- Saves confusion matrix and feature importance plots
- Saves model to `models/`

### 4. Real-time recognition (Step 3)

```bash
python 3_recognize_realtime.py
```

- Opens webcam and loads trained model
- Shows recognized gesture + confidence in real-time
- (Optional) Sends commands to Arduino
- Press **Q** to quit

## 🤖 Arduino Setup (Optional)

If you have a robot arm connected via Arduino:

1. Upload `arduino/robot_arm.ino` to your Arduino board
2. Connect 5 servo motors to pins 3, 5, 6, 9, 10
3. In `config.py`, set:
   ```python
   ARDUINO_ENABLED = True
   ARDUINO_PORT = "/dev/ttyUSB0"  # or "COM3" on Windows
   ```

## ⚙️ Configuration

All settings are in **config.py**. Key things to change:

| Setting | Default | Description |
|---|---|---|
| `NUM_SAMPLES_PER_GESTURE` | 200 | Number of images to collect per gesture |
| `MODEL_TYPE` | `"random_forest"` | Choose `"random_forest"` or `"neural_network"` |
| `CAMERA_INDEX` | 0 | Webcam index (0=default, 1=external) |
| `ARDUINO_ENABLED` | False | Enable Arduino serial communication |

## 🧠 How It Works

### Feature Extraction

MediaPipe detects **21 hand landmarks** (3D coordinates x, y, z). We:

1. Translate landmarks so the **wrist is at origin** (0,0,0)
2. Scale by maximum distance from wrist → **normalized [−1, 1]**
3. Flatten to a **63-dimensional feature vector** (21 × 3)

### Classification

- **Random Forest** (200 trees, max depth 20): ensemble of decision trees
- **Neural Network** (128→64→32, MLP): multi-layer perceptron

### Gesture Smoothing

A **voting buffer** of last 5 predictions prevents flickering:
most common gesture in the buffer is displayed.
